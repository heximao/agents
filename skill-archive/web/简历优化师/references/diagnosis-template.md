# 简历诊断输出格式模板

## 标准诊断输出结构

```
🔴 致命问题（立即修复）：
- [具体问题描述 + 修改建议]
- [每项单独一行，简洁明了]

🟡 优化建议（加分项）：
- [具体问题描述 + 修改建议]
- [非致命但影响评分的问题]

🟢 做得好的地方：
- [亮点描述]
- [保持并可能强化的部分]

📊 综合评分：X/10
```

---

## 诊断维度详解

### 1. 弱动词检测

**常见弱动词清单：**
- 负责、参与、协助、配合
- 做了、处理、帮助、提高
- 搞定、完成、进行

**检测方法：**
逐条检查工作经历中的动词，标记所有弱动词。

**输出示例：**
```
🔴 弱动词问题：
- 第2段经历中"负责用户增长工作"→建议改为"主导用户增长工作"
- 第3段经历中"参与项目开发"→建议改为"协同完成项目开发"或"独立负责XX模块开发"
```

---

### 2. 量化数据检测

**应包含的数据类型：**
- 金额：成本、收入、预算规模
- 百分比：增长率、降低率、转化率
- 规模：用户数、团队人数、项目规模
- 时间周期：项目周期、迭代周期

**检测方法：**
检查每条工作经历是否包含至少一个数字。

**输出示例：**
```
🟡 缺少量化数据：
- 第1段经历缺少具体成果数据，建议补充：
  - 用户增长具体数字（如：新用户增长15万+）
  - 效率提升百分比（如：获客成本降低40%）
```

---

### 3. 格式检测

**检查项目：**
- 时间线是否倒序排列（最近的工作在前）
- 模块是否清晰（个人信息、工作经历、教育背景、技能证书）
- 字数是否适中（A4一页为佳，不超过两页）
- 排版是否一致（字体、间距、标点）

**输出示例：**
```
🟢 格式规范：
- 时间线倒序排列✓
- 模块清晰分明✓

🟡 排版优化：
- 建议统一使用中文标点，当前存在中英文标点混用
- 行间距建议调整为1.15倍，提升阅读体验
```

---

### 4. 关键词密度检测

**检测方法：**
1. 提取目标岗位JD中的关键词
2. 检查简历中是否出现这些关键词
3. 计算关键词覆盖率

**输出示例：**
```
🟡 关键词匹配：
- JD要求"数据分析"能力，简历中出现1次→建议强化相关经历
- JD要求"跨部门协作"，简历未体现→建议补充相关案例
- 关键词覆盖率：65%（建议达到80%以上）
```

---

### 5. 个人信息风险检测

**高风险信息清单：**
- 照片（非必须，可能引入偏见）
- 婚育状况
- 具体出生日期
- 身份证号
- 家庭详细地址

**输出示例：**
```
🔴 个人信息风险：
- 简历中包含照片→建议删除（除非应聘模特/演员等特殊岗位）
- 填写了婚育状况→建议删除，避免歧视风险
```

---

## 完整诊断示例

```
🔴 致命问题（立即修复）：
- 第2段经历使用弱动词"负责"，建议改为"主导"并补充量化数据
- 简历包含照片和婚育状况，建议删除以避免潜在歧视

🟡 优化建议（加分项）：
- 第1段经历缺少具体成果数字，建议补充用户增长数据
- 技能模块未体现JD要求的"数据分析"能力
- 关键词覆盖率为65%，建议提升至80%以上

🟢 做得好的地方：
- 时间线倒序排列规范
- 模块结构清晰
- 第3段经历使用了量化数据（成本降低30%）

📊 综合评分：6.5/10
建议优先修复致命问题，再逐步优化其他部分。
```
