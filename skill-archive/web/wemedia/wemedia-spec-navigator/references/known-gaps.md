# wemedia 规范已知问题清单

> 发现日期：2026-06-05
> 状态：待修复

## 1. SPEC.md 缺失

**问题**：根目录 CLAUDE.md 多次引用 `SPEC.md` 作为开发/命名/脚本的权威规范：
- "任何开发、命名和自动化脚本修改，必须优先读取、遵循根目录下的 `SPEC.md` 规范"
- "所有文件操作须遵循 SPEC.md 中的命名规范"

但 `SPEC.md` 文件**从未创建**。实际规范分散在 CLAUDE.md + 09-rules/ + 01-account/ 中。

**影响**：自动化脚本如果尝试读取 SPEC.md 会找不到文件。新 agent 入驻时会困惑。

**建议**：要么创建 SPEC.md 整合现有规范，要么修改 CLAUDE.md 中的引用指向实际文件。

## 2. 雪球规则检查清单与正文矛盾

**问题**：`09-rules/雪球平台推荐规则与排版规范.md` 中存在矛盾：

- **2.1 节（正文）**：开头格式为 `@今日话题` + `#话题标签#`，话题标签"根据文章内容选择"
- **检查清单**：写的是 `@今日话题 #雪球星计划#`（必选，不可缺一）
- **根目录 CLAUDE.md**：明确说"账号目前**未加入**`#雪球星计划#`，不要添加该话题"

**影响**：AI 排版时如果读检查清单会错误添加 #雪球星计划#。

**建议**：更新检查清单，将 `#雪球星计划#` 改为"至少一个与内容相关的话题标签"。

## 3. 公众号平台规则为空

**问题**：`09-rules/公众号平台推荐规则.md` 为 0 字节空文件。

**影响**：公众号排版无规则可参照，AI 只能依赖 CLAUDE.md 中的简要说明。

**建议**：补充公众号排版规范，至少包含：
- 标题规范（字数、风格）
- 正文排版（字号、段落间距、引用格式）
- 封面图要求
- 摘要/预览文字规范
- 发布前检查清单

以下文件混在 rules 目录中，不是规范文档：
- `xueqiu_.md` — 示例文章（雪球标普500分析）

- `Kimi-2.5、GLM-5 和 MiniMax-M2.5分配-gemini.md` — 模型分配配置
