# 质量校验清单

本清单包含两个层面的质量评估：一是**风格分析报告**的质量，二是**模仿创作输出**的质量。每个维度都包含**低分修复指引**——评出低分后，直接告诉你从哪一步开始修复。

---

## 层面一：风格分析报告质量校验 (Analysis Report Quality)

### 1. 恒定性验证 (Invariance Check)

- [ ] **多样本佐证**：报告中所声称的任何"恒定特征"，是否在 3 篇及以上的样本文章中实际出现？
- [ ] **非偶然现象**：确认所谓的"特征"不是由于某一篇样本的特定话题偶然引入的。

**低分修复**：如果恒定特征不恒定，返回 Phase 4 重新交叉对比。具体做法：
1. 把所有文章的同一维度结果并排列出
2. 逐行检查：哪些在 3+ 篇中出现？哪些只在 1-2 篇中出现？
3. 只保留 3+ 篇中出现的作为"恒定特征"
4. 其余归入"适应特征"，并分析与主题的关联

### 2. 适应性验证 (Adaptability Check)

- [ ] **主题关联性**：对"适应特征"的划分是否清晰？是否能合理解释：作者为什么在此主题下使用 A 句式，而在彼主题下使用 B 句式？
- [ ] **过渡点定位**：是否准确指出了作者在不同主题下风格平滑过渡的微调手段？

**低分修复**：如果适应特征没有主题关联，返回 Phase 4 补充分析：
1. 对每个适应特征，问："这个特征出现在哪些文章中？这些文章有什么共同主题？"
2. 写出关联句："当写[主题A]时，作者会[适应行为]，因为[原因]"
3. 如果找不出关联，这个特征可能不是"适应特征"而是"噪声"——考虑删除

### 3. 特征粒度验证 (Granularity Check)

- [ ] **避免假大空**：检查是否有诸如"作者用词精准"、"情感真挚"、"逻辑严密"等空洞套话。所有特征描述必须有具体的量化或模式化定义（例如："段落平均 120 字"、"长句与短句呈 3:7 交替"、"习惯使用'破局'和'认知黑洞'"）。
- [ ] **具体用例支撑**：核心特征是否都附带了原样本中的具体例句或结构片段作为支撑？

**低分修复**：如果特征描述空洞，返回 Phase 2/3 补充具体数据：
1. 对每个"假大空"特征，问："这个特征的能量化吗？能量化的就量化（统计数字），不能量化的就给具体例句"
2. "用词精准" → "高频使用专业术语，每 100 字出现 3-4 个行业术语"
3. "逻辑严密" → "每篇文章都使用递进式论证，论点链条为 A → B → C → D"
4. "情感真挚" → "情感强度 3 级，通过个人经历引发共鸣，不直接表达情感"

### 4. 结构完整度验证 (Completeness Check)

- [ ] **模板对齐**：输出的 JSON 格式是否与 `examples/author-profile-template.json` 完全一致？是否有遗漏的核心板块？

**低分修复**：如果结构不完整，对照模板逐项检查，补充缺失板块。

## 层面二：模仿创作输出质量校验 (Imitation Output Quality)

在生成新文章或审查模仿初稿时，对照以下指标打分评估（1-5 级，5 为最佳）：

### 1. 逻辑保真度 (Logic Fidelity)

- [ ] **思维对齐**：新文章的切入角度和论证深度是否符合目标作者的认知模型？是否有浅尝辄止或纯堆砌词汇的现象？
- [ ] **框架对齐**：文章大纲是否严密遵循作者常用的结构模式？

**低分修复（< 3 分）**：回到 Level 1 重新构建思维层：
1. 检查认知框架是否正确注入（不是换个词就叫注入框架）
2. 检查论证链条是否与作者的逻辑类型一致（递进/对比/归纳/演绎）
3. 检查评价标准是否用了作者的标准（效率？公平？创新？）
4. 如果思维层没问题但分数仍低，检查结构层是否遵循了作者的框架

### 2. 节奏与排版保真度 (Tempo & Layout Fidelity)

- [ ] **句长节奏**：长句与短句的交替、逗号与句号的使用节奏是否与作者习惯一致？读起来是否有同样的呼吸感？
- [ ] **段落划分**：段落长短和排版层次（如：标题、加粗、空行、引用块）是否还原了原作的视觉美感与节奏张力？

**低分修复（< 3 分）**：回到 Level 2 重新规划节奏层：
1. 统计新文章的长短句比例，与分析报告对比
2. 统计段落平均长度，与分析报告对比
3. 检查标题/加粗/引用块的使用频率是否与作者一致
4. 如果节奏差异大，逐段调整：长段拆短、短段合并、加粗强调位置调整

### 3. 语言指纹保真度 (Linguistic Fingerprint Fidelity)

- [ ] **标志词汇自然融入**：原作者的核心特征词、口头禅是否自然融入了新文章？是否出现了生硬套用的违和感？
- [ ] **修辞指纹复刻**：修辞方法（如：特定领域的类比、反问频率）是否与原风格相称？

**低分修复（< 3 分）**：回到 Level 4 重新润色语言层：
1. 检查特征词汇的融入方式：是自然出现在语境中，还是硬塞进去的？
2. 如果生硬，尝试换一个语境让特征词汇自然出现
3. 检查修辞手法：如果作者爱用类比，新文章是否也用了类比？类比的领域是否合适？
4. 如果词汇融入没问题但分数仍低，检查句式是否还原了作者的标志性句式

### 4. 去噪与去 AI 感过滤 (Slop Removal & Authenticity)

- [ ] **无典型 AI 套话**：确认文章中没有出现以下 AI 常用表达（除非原作者有极特殊的极高频使用习惯）：
  - 值得注意的是、总而言之、深入探讨、如前所述、不可否认
  - 在当今社会、综上所述、众所周知、从某种意义上说
  - 具有重要意义、一定程度上、相关研究表明
- [ ] **无过度模仿**：检查是否由于过度追求风格表现而导致新文章表达累赘、辞藻堆砌、或破坏了原本流畅的叙事？

**低分修复（< 3 分）**：执行去 AI 感专项修复：
1. 逐段扫描上表中的 AI 套话，标记所有出现位置
2. 逐个替换：用作者风格的表达替代 AI 套话（参考 `references/imitation-strategies.md` 的"去 AI 套话指南"）
3. 检查替换后文章是否仍然流畅
4. 如果过度模仿导致累赘，删除不必要的特征词汇，保留自然出现的即可

## 综合评分与修复流程

### 评分计算

对层面二的 4 个维度分别打分（1-5 级），计算平均分。

### 评分判定与行动

| 综合评分 | 状态评级 | 后续行动 |
|---|---|---|
| **平均分 4.5+** | **完美保真 (High Fidelity)** | 可直接交付，风格还原度高，阅读观感自然。 |
| **平均分 3.5 - 4.4** | **风格神似 (Medium Fidelity)** | 需要进行精细化微调。重点检查：(1) 去 AI 套话；(2) 特征词汇融入的自然度；(3) 句式节奏是否还原。 |
| **平均分 < 3.5** | **保真度不足 (Low Fidelity)** | 必须按以下流程重新修复： |

### 低分修复流程（平均分 < 3.5）

1. **先看哪个维度分数最低**，从最低的开始修
2. **修复顺序**：逻辑保真度 → 节奏保真度 → 语言保真度 → 去 AI 感（按漏斗层级从深到浅）
3. **每个维度修复后重新评分**，确认达到 3.5+ 再修下一个
4. **全部修复后重新计算平均分**，如果仍 < 3.5，回到 Level 1 重新走一遍完整流程

### AI 感专项检测

无论综合评分如何，都必须通过以下 AI 感检测：

1. **扫描 AI 套话**：对照去噪清单逐段扫描
2. **检查开头**：是否有"在当今社会"、"随着...的发展"等 AI 万能开头
3. **检查结尾**：是否有"总而言之"、"综上所述"等 AI 总结标志
4. **检查过渡**：是否有"值得注意的是"、"如前所述"等 AI 过渡标志
5. **检查评价**：是否有"具有重要意义"、"不可否认"等 AI 空洞评价

如果发现任何 AI 套话，必须替换后才能交付。
