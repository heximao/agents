# 微信公众号留言排版 Skill

此技能采用“脚本清理 + 人工（Codex）排版”的混合模式，将杂乱的原始留言内容转化为结构清晰、符合规范的 Markdown 格式。

## 资源索引

### 核心工具 (`scripts/`)
- **`clean-repeated-content.sh`**: 核心清理脚本。利用表情白名单移除头像、base64 图片、时间戳及多余表情。

### 规则引用 (`references/`)
- **`patterns.md`**: 详细的排版规则、空行规范及特殊情况处理。
- **`wechat-emojis.txt`**: 微信表情白名单，确保只删除表情而不误伤文字。

### 示例文件 (`examples/`)
- **`raw-comments.md`**: 原始留言示例。
- **`formatted-comments.md`**: 排版效果参考。

## 标准执行流程

处理排版任务时，请严格遵循以下步骤：

### 1. 自动化清理
运行清理脚本以移除噪音。
```bash
bash ./.Codex/skills/wechat-comment/scripts/clean-repeated-content.sh <文件名>.md
```

### 2. 读取与人工排版
清理完成后，由 Codex 读取文件全量内容，并按照 `references/patterns.md` 中的规范进行结构化排版。

**核心格式规范：**
- **用户块**：`用户名（地区）`（加括号，不加粗），换行即为留言内容。
- **作者块**：统一标识为 `作者`，换行即为回复内容。
- **分隔线**：每组对话（留言+回复）之间使用 `---` 分隔。
- **空行**：姓名与内容间不空行；回复前空一行；分隔线前后空一行。

### 3. 核对
- **内容核对**：确保所有有效文字内容已保留，地区和回复关系正确。

## 注意事项
- **严禁删文**：除完全重复的留言外，严禁删除任何文字内容。
- **精确匹配**：表情清理必须基于白名单，严禁使用模糊匹配以免误删方括号内的有效信息。
- **理解语境**：利用 Codex 的语义理解能力处理复杂的回复关系（如“回复 XX：”）。
