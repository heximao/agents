# 金渐成风格模仿执行指南

本指南是 SKILL.md 的补充，提供更细粒度的操作指令。仿写时先按 SKILL.md 的四层漏斗执行，遇到具体问题时查阅本指南。

---

## 一、逐篇仿写操作流程

### Step 1: 搭建骨架（5 分钟）

1. 写出当天的市场数据（或给定主题的核心数据），作为文章第一句话
2. 列出要分析的 3-5 个具体对象（个股/板块/事件），每个对象 1-2 句话
3. 确定结尾的感悟方向和类比意象
4. 输出三级大纲：
   ```
   开头：[具体数据]
   中间：
     - [对象1]：数据 + 操作/判断
     - [对象2]：数据 + 操作/判断
     - [对象3]：数据 + 操作/判断
   结尾：[感悟方向] + [类比意象]
   ```

### Step 2: 填充数据层（10 分钟）

1. 每个对象写出具体数字（涨跌幅、收盘价、买入/卖出节点）
2. 每个数字配一句操作说明或判断
3. 检查：每 200 字至少 1 个具体数字

### Step 3: 填充逻辑层（10 分钟）

1. 对每个对象的判断，确保有递进——不止于"涨了"或"跌了"，要给出"为什么"和"这意味着什么"
2. 在分析之间穿插 1-2 句投资哲学或生活感悟
3. 确保至少有 1 个反直觉判断（与大众认知不同的观点）

### Step 4: 调整语言层（10 分钟）

1. 逐句检查：短句是否占 70%+
2. 逐段检查：是否 2-3 句一段
3. 检查连接词：是否用了"然而"、"因此"等书面词？替换成"但"、"所以"
4. 检查人称：是否全用"我"？是否误用了"我们"？
5. 融入 5-8 个特征词汇（自然融入，不硬塞）

### Step 5: 调整情感层（5 分钟）

1. 扫描感叹号——删掉所有感叹号
2. 扫描直接情感表达（"我很看好"、"我非常担心"）——改为通过事实传递
3. 检查结尾——是否用金句/比喻收束？是否避免了总结前文？
4. 检查讽刺——是否点到为止？是否自嘲式而非攻击式？

### Step 6: 去 AI 感（5 分钟）

1. 逐段扫描禁用表达清单
2. 检查开头——是否是数据/事实？
3. 检查结尾——是否是总结？
4. 检查过渡——是否用了 AI 过渡词？
5. 最终通读——是否有"一看就是 AI 写的"的感觉？

## 二、常见误区提醒

### 误区 1: 只模仿词汇不模仿思维

**错误**：堆砌"负成本"、"金字塔加仓"等术语，但文章逻辑是 AI 式的"从X个方面分析"。

**正确**：先确保思维框架是"周期+纪律+逆向"，再自然融入术语。

### 误区 2: 讽刺过度

**错误**：每段都在嘲讽读者，变成攻击性文章。

**正确**：11 篇样本中，讽刺平均每篇出现 1-2 次，且多为自嘲（"厌蠢症都要发作了"）而非直接攻击。讽刺是调味品，不是主菜。

### 误区 3: 结尾变成总结

**错误**："综上所述，投资最重要的是纪律和耐心。"

**正确**："往池塘里扔个石头，和往大江大河里扔个石头，是完全不一样的。大江大河不会因为一个石头带起的涟漪，改变了潮水的方向。"

### 误区 4: 用"我们"拉读者站队

**错误**："我们要保持冷静，不要追高。"

**正确**："我一直说不要追高。"或"每个人都要结合自己的情况。"

### 误区 5: 过度解释术语

**错误**："金字塔加仓法，顾名思义，就是像金字塔一样，越跌买越多。"

**正确**："出现加仓机会就下手，用金字塔加仓法。"——金渐成假设读者懂，不解释。

### 误区 6: 段落太长

**错误**：一段写 6-8 句，像 AI 的标准段落。

**正确**：一段 2-3 句。个股分析一段 1-2 句。感悟一段 3-4 句。

### 误区 7: 用连接词做过渡

**错误**："接下来，让我们看看生物医药板块。"

**正确**：直接空一行，写"生物医药板块，礼来涨了3.35%"。硬切换，不用过渡词。

## 三、特征词汇使用指南

### 必现词汇（每篇至少出现 3 个）

| 词汇 | 使用场景 | 示例 |
|------|---------|------|
| 负成本 | 描述持仓状态 | "目前英伟达负成本了" |
| 加仓/减仓 | 描述操作 | "设置了225减仓5%" |
| 节点 | 描述价格目标 | "出现220以内的加仓节点" |
| 设置/触发 | 描述自动化操作 | "我设置的225美元减仓5%，顺利卖出" |
| 仓位占比 | 描述持仓结构 | "仓位占比33.5%了，太重了些" |

### 态度词汇（按需使用）

| 词汇 | 使用场景 | 示例 |
|------|---------|------|
| 慢慢等 | 表达耐心 | "慢慢等了，有的是时间" |
| 耐心 | 表达长期主义 | "多给谷歌一点耐心" |
| 有的是时间 | 强调不急 | "如果遇到大跌，我也会捞一把。有的是时间" |
| 不急 | 淡化紧迫感 | "不急，慢慢等" |

### 讽刺词汇（谨慎使用，每篇最多 1-2 个）

| 词汇 | 使用场景 | 示例 |
|------|---------|------|
| 厌蠢症 | 对反复提问的不耐烦 | "问得我厌蠢症都要发作了" |
| 买椟还珠 | 讽刺不识货 | "奈何看的人却比以往少，世人往往这样，买椟还珠" |
| 巨婴 | 讽刺不愿自己动手 | "像个巨婴，饭都要人端着碗，一口一口喂到嘴里" |
| 不浪费一个字 | 表达决绝 | "发现就拉黑，不浪费一个字" |

## 四、类比意象库

仿写时从以下意象中选择合适的类比，也可创造新的日常类比：

### 已有样本中的类比

| 意象 | 类比含义 | 出处 |
|------|---------|------|
| 池塘 vs 大江大河 | 影响力的量级 | 2025-05-28 |
| 放风筝 | 投资需要掌控感 | 2025-09-03 |
| 初恋拉手 | 暴跌抄底的紧张兴奋 | 2025-04-04 |
| 太监去青楼 | 荒谬的政策 | 2025-01-23 |
| 猴子指导赚钱 | 外行指导内行 | 2025-05-28 |
| 潮水的方向 | 宏观趋势不可阻挡 | 2025-05-28 |

### 可迁移的类比方向

- **体育类**：马拉松（长期投资）、短跑冲刺（短线投机）、教练排兵布阵（仓位管理）
- **农业类**：播种收获（投资周期）、施肥浇水（加仓）、除草（减仓）
- **航海类**：风浪（市场波动）、锚（压舱石资产）、航线（投资纪律）
- **建筑类**：地基（基本面）、钢筋（仓位结构）、装修（短期操作）

## 五、句式模板库

### 数据句模板

- "XX涨了/跌了X%，收盘价XX美元。"
- "标普500涨了X%，收盘XXX点；纳指涨了X%，收盘XXX点。"
- "相比最高点，今年纳指跌了X%，标普跌了X%。"

### 操作句模板

- "我设置了XX的买入/卖出节点。"
- "两个新账户在XX设置了加仓。"
- "目前都已经是负成本持股。"
- "触发后，成本会降到XX。"

### 判断句模板

- "我一直说/我一直觉得……"
- "中长期依然看好。"
- "对于XX，我没什么把握。"
- "没什么可以操作的。"

### 态度句模板

- "慢慢等了，有的是时间。"
- "不急，慢慢等。"
- "每个人都要结合自己的情况。"
- "适合自己的才是最好的。"

### 感悟句模板

- "有些东西只有经历了才会懂。"
- "人还是要多经历。"
- "经历真是个有意思的'老师'，让人又爱又恨。"
- "就这样吧。"

### 讽刺句模板

- "省得整天来问我'为什么……'，问得我厌蠢症都要发作了。"

## 六、结尾模板

金渐成的结尾从不总结前文，而是用以下方式收束：

### 模式 A: 生活感悟+金句

```
[生活感悟的叙述，2-3句]

[一句精炼的金句，概括感悟]

就这样吧。
```

### 模式 B: 类比升华

```
[用一个日常场景做类比，2-3句]

[类比的核心启示，1-2句]
```

### 模式 C: 哲理性短句

```
……

[一句有哲理感的短句]
```

### 模式 D: 开放式收尾

```
[一个新角度的思考，不给结论]

[留白，让读者自己想]
```
