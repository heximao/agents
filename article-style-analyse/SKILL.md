# 多篇文章风格分析与仿写 Skill 生成系统

通过多文本交叉分析框架，从 3-5 篇代表作品中提取作者的恒定风格特征，生成**可直接使用的标准化 Skill**。该 Skill 包含详细的模仿执行指南，使 AI 能够高度还原指定作者的写作风格。

核心原则：**思维骨架 > 语言皮肤**。风格的本质是作者看待世界的方式和组织论点的逻辑，而非几个标志性词汇。

## 核心目标

**输入**：3-5 篇目标作者的文章样本
**输出**：一个标准的 Skill（SKILL.md + references/ + examples/），AI 加载后可成功仿写该作者风格

## 样本准备

### 目录结构

在调用本技能时，将目标作者的文章样本放入 `examples/` 目录下的专属文件夹：

```
examples/
└── {作者名}/
    ├── 01_主题A.md
    ├── 02_主题B.md
    └── 03_主题C.md
```

### 命名规范

1. **文件夹命名**：`{作者名}`，例如：`examples/半佛仙人/`、`examples/九边/`
2. **文件命名**：`{序号}_{主题}.md`，序号用于控制分析顺序（建议按质量排序，高质量样本优先）
3. **文件格式**：纯 Markdown（`.md`）格式
4. **样本数量**：3-5 篇，覆盖不同主题

### 样本要求

- 样本应覆盖**不同主题**，以提取跨文本恒定特征
- 样本数量不足 3 篇时，提示用户补充
- 建议选择作者的代表作品，而非随意选取

## 执行流程

### Phase 1: 样本读取与预处理

1. 识别 `examples/` 目录下的子文件夹（作者名），读取文件夹内所有 `.md` 文件
2. 对每篇文章记录：标题、主题类别、字数、发布日期（如有）
3. 识别文章间的主题差异，为后续"恒定 vs 适应"特征分离做准备

### Phase 2: 宏观风格分析

对每篇文章**独立**执行以下提取动作。操作细节见 `references/analysis-framework.md` 的"宏观风格提取技法"。

**逐篇执行：**

1. **提取思维模式**
   - 标记所有论点连接词（"所以"、"换句话说"、"但问题是"），判断逻辑结构类型（递进/对比/归纳/演绎）
   - 识别作者解释世界使用的认知模型（经济学视角？系统思维？历史视角？）
   - 记录作者拆解问题的惯用顺序（先宏观还是先微观？先破后立还是先立后破？）

2. **提取价值取向**
   - 找出作者明确表态的句子，标记立场倾向
   - 统计作者评判事物时使用的标准词（"效率"、"公平"、"创新"、"稳定"）
   - 记录作者在多篇文章中反复强调的领域

3. **提取表达意图**
   - 判断每篇文章的主要目的（告知/说服/娱乐/挑动/共鸣）
   - 识别作者与读者的关系模式（导师型/同行型/质疑型/煽动型）

4. **提取风格定位**
   - 确定体裁类型和写作流派
   - 找 1-2 个风格相似的标杆作者作为参照

5. **提取整体架构**
   - 识别反复出现的组织框架（如"问题-方案-收益"、"现象-本质-预测"）
   - 分析开头引入方式、中间展开方式、结尾收束方式
   - 统计主干论点与辅助信息（案例、引用、数据）的比例

### Phase 3: 微观风格分析

对每篇文章**独立**执行以下提取动作。操作细节见 `references/analysis-framework.md` 的"微观风格提取技法"。

**逐篇执行：**

1. **提取语言特征**
   - 统计长短句比例：数每篇 5 个代表性段落的平均句长
   - 标记出现 2 次以上的句式模式
   - 提取高频词：出现 3 次以上的非功能词
   - 记录修辞手法的具体实例（隐喻的喻体、反讽的对象、排比的结构）

2. **提取结构特征**
   - 统计段落平均长度（句数）
   - 标记段落间的过渡方式
   - 记录标题、加粗、引用块、列表的使用频率

3. **提取叙事策略**
   - 统计视角分布（第一/第二/第三人称各占多少）
   - 判断与主题的心理距离（沉浸式 vs 抽离式）
   - 记录时间线处理方式

4. **提取情感特征**
   - 按 1-5 级评定情感强度，给出判定依据
   - 标记情感表达方式（直抒胸臆 vs 委婉暗示 vs 通过事实引发）
   - 概括情感基调

5. **提取思维特征**
   - 按 1-5 级评定逻辑深度
   - 判断论证节奏（急促论证/沉思式/波浪式）

6. **提取个性标记**
   - 提取标志性表达：出现 2+ 次的口头禅、招牌句式
   - 记录意象系统：反复出现的视觉意象及其隐喻含义
   - 记录标点习惯：破折号、省略号、问号的使用频率

7. **提取文化底蕴**
   - 统计典故引用类型（历史/流行文化/学术理论）
   - 识别跨领域知识整合的模式

8. **提取韵律节奏**
   - 分析长短句交替的规律性
   - 统计标点符号对阅读速度的把控方式

### Phase 4: 跨文本交叉对比

1. **建立对比表**：将所有文章的分析结果按维度并排比较
2. **标记恒定特征**：在 3+ 篇文章中一致出现的特征
3. **标记适应特征**：仅在特定主题下出现的特征
4. **分析适应规律**：适应特征与主题之间的关联（如：写投资时用数据论证，写成长时用故事论证）
5. **定义核心风格**：一句话概括该作者的本质特征
6. **排序恒定特征**：按重要性排列（思维 > 结构 > 情感 > 语言 > 个性标记）
7. **提取"不做什么"**：作者刻意避免的表达方式、论证方式、立场——这往往比"做什么"更能定义风格
8. **识别语言指纹**：作者的标志性词汇、句式和表达习惯——但要与思维框架一起提取，避免表层模仿

### Phase 4.5: 防表层模仿检查

在生成 Skill 之前，执行以下检查：

1. **思维-语言一致性**：如果只换了词汇但思维框架不同，就是表层模仿。确认所有恒定特征都包含思维层面的描述
2. **"不做什么"完整性**：确认已识别出作者刻意避免的表达和论证方式
3. **适应特征归因**：每个适应特征都能解释"为什么在这个主题下这样做"

### Phase 5: 生成标准化 Skill

基于分析结果，生成可直接使用的标准化 Skill 文件：

1. **创建目标作者的 Skill 目录结构**：
   ```
   skills/{author-name}-style/
   ├── SKILL.md
   ├── references/
   │   └── imitation-guide.md
   └── examples/
       └── sample-output.md
   ```

2. **编写 SKILL.md**：使用 `examples/skill-template.md` 作为模板
   - frontmatter 的 name 字段格式：`{作者名}风格仿写`
   - description 包含触发词和功能说明
   - 填充模板中的每个占位符时，参考模板旁的填充说明

3. **编写 references/imitation-guide.md**：写入详细的模仿执行指南
   - 恒定特征的具体操作方法（不是概念描述，是"打开文章后第一步做什么"级别的指令）
   - 主题适配策略
   - 常见误区提醒
   - 去 AI 套话的具体替换规则

4. **在 examples/ 中提供仿写示范**

### Phase 6: 质量校验

对照 `references/quality-checklist.md` 检查输出质量：

**分析质量校验：**
- 恒定特征确实在 3+ 篇文章中出现
- 适应特征有明确的主题关联
- 每个特征都有样本中的具体例句支撑
- 无"表层模仿陷阱"（仅关注词汇忽略思维）

**仿写质量校验：**
- 模仿指南具有可操作性（AI 读完能直接执行，不需要自己脑补）
- 包含去 AI 感的具体规则
- 质量校验清单完整

**如果发现问题**，返回对应阶段修复：
- 恒定特征不恒定 → 返回 Phase 4 重新交叉对比
- 模仿指南不可操作 → 返回 Phase 5 补充具体操作指令
- 存在表层模仿 → 返回 Phase 4.5 补充思维层面描述
- AI 套话未处理 → 返回 Phase 5 补充去 AI 感规则

## 增量更新（可选）

当需要基于新样本更新已有的风格 Skill 时：

### 更新触发条件

- 新增了目标作者的文章样本
- 发现原有分析遗漏了重要特征
- 样本数量达到 8+ 篇时建议重新分析

### 更新流程

1. **追加样本**：将新文章放入 `{作者名}/` 文件夹，命名格式：`{序号}_{主题}.md`
2. **重新执行分析**：对所有样本（包括新旧）重新执行 Phase 2-4
3. **增量对比**：对比新旧结果，更新恒定特征和适应特征
4. **版本更新**：将生成的 Skill 版本号 +1

### 输出覆盖

更新时直接覆盖原有 Skill 文件，保留版本历史（通过 version 字段）。

## 输出规范

生成的标准化 Skill 必须包含以下文件，**确保 AI 加载后能成功仿写**：

1. **SKILL.md** — 核心文件，必须包含：
   - 正确的 YAML frontmatter（name、description）
   - **风格定义**：一句话概括作者的核心风格特征
   - **核心恒定特征**：5 个维度的详细描述（思维模式、结构框架、语言风格、情感基调、个性标记）
   - **模仿执行步骤**：分层的漏斗模型（Level 1-4），按顺序执行，每步都是具体操作指令
   - **主题适配策略**：保留项和调整项
   - **质量校验清单**：可执行的检查项，包含去 AI 感检查

2. **references/imitation-guide.md** — 详细执行指南（可合并到 SKILL.md 或单独存放）：
   - 恒定特征的具体操作方法
   - 常见误区提醒
   - 主题适配的详细步骤
   - 去 AI 套话的替换规则

3. **examples/** — 示例目录：
   - 仿写示范文本（1-2 篇），展示按照本 Skill 仿写的实际效果

**生成的 Skill 必须满足以下条件才能验收**：
- AI 加载后无需额外提示即可执行仿写
- 模仿执行步骤具体、可操作（像操作手册，不是概念说明）
- 质量校验清单完整
- 包含去 AI 感的具体规则

输出后，向用户说明新 Skill 的存放位置、使用方法和质量校验结果。

## 使用建议

- **质量优先**：样本的多样性直接决定模型的健壮性
- **内核驱动**：重点关注"逻辑骨架"与"思考视角"，而非单纯的词汇模仿
- **分离恒定与适应**：区分作者不变的核心风格和随主题调整的适应性特征
- **直接可用**：生成的新 Skill 必须可以直接被 AI 加载使用，无需额外配置
- **去 AI 感**：仿写最忌讳的不是"不够像作者"，而是"一看就是 AI 写的"。必须在 Skill 中内置去 AI 套话规则
