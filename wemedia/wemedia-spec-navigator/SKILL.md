# wemedia 项目规范导航

## 规范文件地图

项目规范**没有统一的 SPEC.md**（CLAUDE.md 多次引用但文件不存在），实际分散在三处：

```
CLAUDE.md（根目录）          ← 总纲：管线、状态表、目录框架、选题体系
09-rules/                    ← 写作硬约束 + 平台排版规则
01-account/{平台}/{账号}/    ← 作者画像 + 账号定位
```

### 加载顺序（写作前必读）

1. **CLAUDE.md** — 理解管线阶段和状态流转
2. **作者画像** — 根据作者选择对应文件（见下表）
3. **写作硬约束** — `09-rules/金渐成文章写作硬约束.md`（23条）
4. **平台规则** — 按目标平台选择（见下表）

## Pitfalls

- ❌ **不要假设 SPEC.md 存在** — CLAUDE.md 引用了它但文件从未创建
- ❌ **不要用雪球检查清单的 #雪球星计划#** — CLAUDE.md 明确说账号未加入，不要添加（检查清单与正文矛盾）
- ❌ **不要给金渐成写独立操作建议段落** — 23条硬约束第1条，必须自然穿插在分析中
- ❌ **不要在正文用 ## 分段标题** — 金渐成文章以自然段落衔接
- ⚠️ **公众号平台规则为空** — `09-rules/公众号平台推荐规则.md` 是 0 字节，需要补充
