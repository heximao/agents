# 雪球爆款标题写作 - 使用示例

## 示例一：股票分析类标题

### 用户输入
```
分析宁德时代的基本面：
- 市占率全球第一
- 技术壁垒高
- 但估值偏高，短期有回调风险
- 长期看好新能源赛道
```

### Skill输出
```
为您生成以下雪球爆款标题：

【数字量化型】
1. 持有宁德时代2年，我对"高估值"的新理解
2. 宁德时代回调20%，是机会还是陷阱？

【质疑共识型】
3. 都说宁德时代太贵了，我为什么还在看？

【警示预警型】
4. 宁德时代的这个信号，让我开始谨慎了

【身份认同型】
5. 作为新能源投资者，宁德时代教会我的事

推荐使用标题1或2，数字要素明确，符合雪球用户偏好。
```

## 使用提示

1. **提供足够信息**：用户输入内容越详细，生成的标题越精准
2. **包含数字要素**：收益率、时间、金额等数字是雪球标题的核心元素
3. **选择推荐标题**：Skill会标注推荐标题，通常是最符合雪球用户偏好的
4. **避免荐股嫌疑**：标题中避免直接荐股，改为展示分析过程或观点
5. **真实数据优先**：编造的数字会损害信任，使用真实数据

---

## 注意：标题与内容匹配

Skill生成的标题必须与用户提供的实际内容匹配，不可出现以下情况：

❌ 错误示例：
- 标题说"亏损50%"，内容却是盈利
- 标题说"持有8年"，内容只持有了1年
- 标题暗示有具体结论，内容却没有明确观点

✅ 正确示例：
- 标题和内容中的数字一致
- 标题暗示的观点在内容中有支撑
- 标题的情绪基调与内容匹配
