# 雪球爆款标题写作 Skill

## 概述

为雪球平台创作高点击率、高传播力的5-10个爆款标题。基于雪球用户群体特征（投资者、理财人群）和平台内容特性（股票分析、市场观点、投资心得），运用二极管标题法、情绪触发点、数字量化等技巧生成标题。

## 雪球平台特征

### 用户画像
- **核心人群**：股票投资者、基金持有人、理财人群
- **内容偏好**：实盘干货、深度分析、真实经历、逆向观点
- **情绪触发点**：亏损共鸣、暴富梦想、踩雷警示、逆袭故事

### 内容类型与标题策略

| 内容类型 | 用户痛点 | 标题方向 |
|---------|---------|---------|
| 股票分析 | 不知买点/卖点 | 给出明确信号 + 风险提示 |
| 市场观点 | 看不清趋势 | 判断性观点 + 逻辑支撑 |
| 投资心得 | 重复犯错 | 血泪教训 + 可复制方法 |
| 组合动态 | 收益焦虑 | 真实盈亏 + 时间周期 |

## 爆款标题公式

### 公式一：数字量化 + 结果导向
```
[数字]年/[金额]元 + [具体动作] + [结果]
例：3年50万，我只做对了这一件事
例：从亏损80%到盈利，这只股我拿了900天
```

### 公式二：情绪对立 + 真实经历
```
[负面情绪] + [转折] + [正面结果]
例：以为踩雷了，结果翻倍了——这只股教我的事
例：从被嘲笑到被关注，我的抄底之路
```

### 公式三：质疑共识 + 逆向观点
```
[主流观点] + [质疑] + [替代观点]
例：都说这只股要凉，我为什么还在加仓？
例：牛市里，我最害怕的竟是这个
```

### 公式四：警示预警 + 时间紧迫
```
[危险信号] + [时间限定] + [行动建议]
例：这只股的信号，让我想起2015年
例：明天开盘，千万记住这一点
```

### 公式五：身份认同 + 圈层共鸣
```
[身份标签] + [共同经历] + [结果/感悟]
例：股民十年，我终于明白了一个道理
例：作为散户，我在机构重仓股上学到的事
```

## 禁忌与红线

### ❌ 绝对禁止
1. **荐股嫌疑**：避免"这只股必涨"、"快买这只"
2. **虚假承诺**：禁止"稳赚不赔"、"年化100%"
3. **制造恐慌**：不夸大市场风险，不散布谣言
4. **标题党欺骗**：标题内容必须与正文匹配

### ⚠️ 需谨慎
1. **敏感数据**：收益数字需真实，不编造
2. **时间表述**：避免模糊的"最近"、"不久"
3. **平台规则**：不违反雪球社区公约

## 标题创作流程

### Step 1: 明确内容类型
识别用户提供的内容属于哪种类型：
- 股票分析 → 使用公式一、四
- 市场观点 → 使用公式三、四
- 投资心得 → 使用公式二、五
- 组合动态 → 使用公式一、二

### Step 2: 提取关键信息
从用户内容中提取：
- **数字要素**：收益率、持仓时间、金额、次数
- **情绪要素**：焦虑、兴奋、后悔、惊喜、恐惧
- **冲突要素**：多空分歧、认知偏差、预期落差
- **身份要素**：散户/机构、新手/老手、盈利/亏损

### Step 3: 选择标题公式
根据内容特点选择1-2个最合适的公式，各生成2-3个备选标题。

### Step 4: 优化标题细节
- 控制长度：15-25字为宜
- 检查合规：无荐股、无虚假承诺
- 测试吸引力：是否有情绪触发点

### Step 5: 输出结果
提供3-5个不同方向的标题供用户选择，并说明每个标题的亮点。

## 使用示例

### 示例一：股票分析
**用户输入**：分析比亚迪的基本面，认为长期看好，但短期有回调风险。

**生成标题**：
1. 比亚迪回调30%，是机会还是陷阱？（质疑共识）
2. 看好比亚迪的第三年，我在等什么？（数字量化）
3. 这只新能源龙头，让我重新理解了"持有"（身份认同）

### 示例二：投资心得
**用户输入**：分享自己从追涨杀跌到价值投资的转变经历，以前亏了很多，现在稳定盈利。

**生成标题**：
1. 亏损50万后，我终于学会了"不操作"（情绪对立）
2. 从韭菜到盈利，我做了这一个改变（数字量化）
3. 股市十年，这3次亏损教我的事（身份认同）

### 示例三：市场观点
**用户输入**：认为当前市场处于底部区域，是布局良机，但很多人还在恐慌。

**生成标题**：
1. 别人恐慌时，我在做什么？（质疑共识）
2. 这个信号，让我想起2018年底（警示预警）
3. 底部的特征，这次也不例外（身份认同）

## 注意事项

1. **真实性优先**：雪球用户对虚假内容敏感，标题必须与内容匹配
2. **风险意识**：财经内容天然带风险，标题要体现审慎
3. **专业度**：避免过度娱乐化，保持财经内容的专业调性
4. **数据支撑**：有数据的内容更容易被信任，标题中尽量体现
