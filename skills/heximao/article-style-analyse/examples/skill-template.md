## 模仿执行步骤（分层漏斗模型）

按以下层级顺序执行，**不可颠倒顺序或跳过层级**。每一步都是具体操作，不是概念说明。

### Level 1: 逻辑与思维层（最重要）

1. **确定切入视角**：先确定文章从哪个角度切入，使用 {作者的典型切入方式}
# ↑ 示例："找一个微观案例（一家公司、一个人、一个现象）作为切入点，不要从宏观趋势切入"

2. **注入认知框架**：使用 {作者的认知框架} 分析问题
# ↑ 示例："用经济学框架分析：这个现象的成本是什么？收益是什么？激励结构是什么？信息不对称在哪里？"

3. **构建论证逻辑**：按照 {论证结构} 组织论点，确保逻辑链条完整
# ↑ 示例："按递进式组织：现象 → 表面原因 → 深层原因 → 本质规律。每层用'但问题是'、'更关键的是'推进"

4. **设定评价标准**：使用作者的价值观和评判标准来评判新主题
# ↑ 示例："用效率和博弈的标准评判：这件事的投入产出比是多少？谁在博弈中占优？"

### Level 2: 结构与大纲层

1. **选择框架**：采用 {常用框架模式} 构建三级大纲
# ↑ 示例："现象-本质-预测框架：(1) 数据/故事引入现象 (2) 深挖 2-3 个本质原因 (3) 趋势判断或行动建议"

2. **规划节奏**：控制 {段落长短交替规律}
# ↑ 示例："数据分析用长段（4-5 句），观点强调用短段（1-2 句）。每个大论点后跟一个短段强调"

3. **安排信息密度**：规划案例、引用、理论模型的密度（{高/中/低}）
# ↑ 示例："中密度——每 500 字 1-2 个案例或数据点，不堆砌但有实证支撑"

4. **设计开头与结尾**：使用 {开头手法} 引入，{结尾手法} 收束
# ↑ 示例："开头用反直觉数据抛出，结尾用金句收束——一句话概括核心观点"

### Level 3: 叙事与情感层

1. **设定叙事视角**：使用 {第一人称/第二人称/第三人称}
# ↑ 示例："第一人称复数'我们'，偶尔用'我'分享个人经历"

2. **把控情感距离**：与主题保持 {沉浸式/抽离式} 的心理距离
# ↑ 示例："抽离式——冷静观察，不带个人情感色彩"

3. **控制情感强度**：保持 {强度级别} 的情感表达
# ↑ 示例："2 级——克制，偶有冷幽默，绝不煽情"

4. **建立读者关系**：建立 {作者-读者关系模式}
# ↑ 示例："同行型——分享观察和思考，不说教，不居高临下"

### Level 4: 语言与修辞层（最后执行）

1. **控制句式**：按照 {长短句比例} 调整句长
# ↑ 示例："70% 短句 + 30% 长句。标志性句式：'不是...而是...'、'本质上是...'"

2. **融入特征词汇**：自然融入以下词汇：{特征词汇列表}

3. **使用修辞手法**：使用 {偏好的修辞手法}

## 主题适配策略

当写作主题与样本文章不同时：

### 保留项（不变）

- 思维框架和认知模型
- 结构模式和节奏特征
- 情感基调和读者关系
- 标志性表达和句式偏好

### 调整项（适配）

- 词汇替换：用新主题术语替换旧主题术语，保持使用密度一致
- 类比迁移：寻找新主题中等效的类比源
- 正式度微调：根据新主题要求调整用词正式度

## 去 AI 感规则

仿写必须通过以下检查，否则不能交付：

**禁止使用的表达**：
- 值得注意的是、总而言之、深入探讨、如前所述、不可否认
- 在当今社会、综上所述、众所周知、从某种意义上说
- 具有重要意义、一定程度上、相关研究表明

**替换策略**：
- AI 开头（"在当今社会"）→ 用作者的开头方式（数据/故事/反直觉事实）
- AI 总结（"总而言之"）→ 用作者的结尾方式（金句/升华/开放反思）
- AI 深度预告（"深入探讨"）→ 直接开始分析，不需要预告
- AI 让步（"不可否认"）→ 直接说"确实"或用作者的让步方式

## 质量校验清单

完成仿写后，必须逐项检查：

- [ ] **逻辑保真**：切入视角是否符合作者的认知框架？论证深度是否足够？
- [ ] **结构保真**：大纲是否遵循常用框架模式？段落节奏是否还原？
- [ ] **语言保真**：句式长短比例是否还原？特征词汇是否自然融入？
- [ ] **情感保真**：情感基调是否一致？读者关系是否正确？
- [ ] **去 AI 套话**：是否移除了所有禁止使用的 AI 表达？
- [ ] **去生硬模仿**：是否存在为了仿写而破坏流畅性的情况？
