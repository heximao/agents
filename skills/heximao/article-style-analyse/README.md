# 文章风格分析

干什么用？分析作者文章风格，提取核心特征，生成复刻指南。

---

## 怎么用

1. 把作者文章扔进 `examples/` 目录（3-5 篇最好）
2. 对我说"开始分析"
3. 出结果：风格 Profile + 指南 + 适应策略

---

## 输出内容

- **风格概要**：核心特征、稳定性评分
- **恒定特征**：无论写啥都保持的特征（思维、逻辑、表达习惯）
- **适应特征**：按主题/场景调整的部分
- **模仿指南**：优先级排序，从高到低依次学

---

## 关键点

**样本选择**
- 要有代表性，能反映作者真实风格
- 最好覆盖不同主题、长度、场景
- 3-5 篇就够，太少识别不准

**分析侧重**
- 关键看逻辑骨架、论证方式（比词汇选择更稳定）
- 抓作者的文章组织套路
- 感受节奏感（段落长短、信息密度）

**用输出时**
- 模仿指南按优先级排，从第一项开始学效率高
- 记录常见误区，别重复踩坑
