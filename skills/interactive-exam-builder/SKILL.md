# 交互式模拟卷生成器

## 适用判断

- 用户要"模拟试题/练习题库"，并强调**交互**（点了就判卷、能看解析、能导航）→ 用本 skill。
- 用户要的是**打印版/正式文档**（docx、pdf）→ 不走这里，走 Office 文档链路。

## 目录约定

生成一套卷子时，在输出目录下放三件东西并长期复用：

| 文件 | 作用 |
|---|---|
| `exam_template.html` | 唯一模板，所有交互逻辑与样式都在这里，含占位符 `__DATA__`、`__H1__`、`__KICKER__`、`__SUB__`、`__NOTICE__`、`__STORE__` |
| `build_exam_html.py` | 解析 Markdown 草稿 → JSON → 灌进模板；配置驱动，一次可构建多科 |
| `smoke_test.js` | jsdom 冒烟测试，传 HTML 路径即可 |

题目 Markdown 草稿按科目分目录：`{科目}/stage1/final_draft.md`。

## 草稿 Markdown 规范（解析器依赖，必须严格遵守）

```
## 第一部分 试题

### 第一章 XXX（第 1—7 题）

**1.** 题干……（　）。

A. 选项
B. 选项
C. 选项
D. 选项

**33.** 组合型题干（　）。

Ⅰ. 子项
Ⅱ. 子项
Ⅲ. 子项
Ⅳ. 子项

A. Ⅱ、Ⅲ、Ⅳ
B. Ⅰ、Ⅱ、Ⅲ
...

**阅读下列材料，回答第 43—44 题。**

> 材料正文（可多行）

**43.** ...
```

解析要点（踩过坑）：
1. **材料块**：提示行与 `>` 引用块之间**可能夹一个空行**，采集引用块前必须先跳过空行，否则 4 道材料题全部丢材料。
2. 题号用 `**N.**` 包裹；选项行以 `A. `—`D. ` 开头；子项用 `Ⅰ.`—`Ⅳ.`。
3. 解析区统一写成 `N. **X。** 解析正文`，**答案速查表由解析反向自动生成**，不要手抄（手抄必错位）。

## 交互规则（已定型，勿回退）

- **作答**：点击选项或按 `1/2/3/4` → A/B/C/D；`←` `→` 翻页；`N` 跳未答。
- **改答**：练习模式随时可改；考试模式**交卷前**可改、**交卷后**锁定。实现上：
  - `choose()` 只在 `mode==='exam' && submitted` 时拦截；新值与旧值相同则忽略。
  - `paint()` 的 `disabled` 条件收窄为 `mode==='exam' && submitted`，判卷着色按当前 `answers` 重算。
  - 选中项右侧显示「已选」徽标；反馈区显示"可点选其他选项（或按 1-4）修改"。
  - `setMode('practice')`（含"逐题回看"）会清 `submitted`，即解锁。
- **双模式**：练习＝即时判卷＋解析；考试＝先作答，交卷后出分（默认 60 分合格）＋错题跳转。
- **其他**：题卡 100 格三色（已答/对/错）、计时、`localStorage` 续答、重做清空、手机适配、打印样式。

## 构建与验证

```bash
python3 build_exam_html.py subject1 subject3
```

验证必须用 jsdom 跑真实页面，不要靠肉眼看：

```bash
NODE_PATH=~/.workbuddy/binaries/node/workspace/node_modules \
  node smoke_test.js "某卷（交互版）.html"
```

- jsdom 需先 `npm install jsdom` 到 managed node workspace。
- **偶发 OOM/超时**：加 `--max-old-space-size=1024`；仍慢就用 `run_in_background` 并把输出写日志文件，前台 120s 超时会被 SIGTERM。
- 冒烟要覆盖：数字键作答、判卷着色、**改答链路（改对→正确率上升、题卡变绿、改回→回滚）**、←→ 翻页、材料/组合题渲染、交卷计分、交卷锁定、回看解锁、重做、持久化。

## 命题质量

- 答案分布尽量均匀（A/B/C/D 各 25 左右），别让正确项扎堆在某个字母。
- **答案均衡化脚本（已踩坑）**：写完题后答案常严重偏向 A（如 A59/B25/C9/D7），需要脚本重排。做法：
  1. 生成均衡目标序列（`['A','B','C','D']*25` 后 `random.shuffle`，固定种子可复现）。
  2. **禁止整行交换**——整行交换会把行首字母标记一起搬走，导致顺序变成 `C. / B. / A. / D.`、答案指向错误文本。
  3. 正确做法：只重排**选项文本**，写出时按物理位置 0..3 重新赋字母 `A. / B. / C. / D.`；正确文本 = 物理位置 `idx(target)` 处的文本（整行交换后其行标记即原答案字母）。
  4. 重排后必做三项校验：每题字母序列为 A,B,C,D；四个选项文本互不重复；抽查计算题「答案字母指向的文本 == 解析里的数值」。
- 若解析正文引用了选项字母（如"A、B、D 均正确"），重排前必须先改成不引用字母的表述，否则重排后解析自相矛盾。
- 数字类考点（金额、比例、时限、天数）出卷后**逐条联网复核**，法条出处与数字写错会误导备考。
