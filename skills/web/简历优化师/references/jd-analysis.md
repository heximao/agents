# JD分析完整框架

## JD分析流程

### Step 1: 解析硬技能关键词

**硬技能类型：**
- 编程语言（Python、Java、Go）
- 工具平台（Excel、Tableau、Power BI）
- 技术框架（React、Spring、TensorFlow）
- 专业证书（CPA、PMP、AWS认证）
- 行业知识（金融风控、医疗合规）

**提取方法：**
逐句扫描JD，提取所有具体的技术名词。

---

### Step 2: 提取软技能关键词

**软技能类型：**
- 沟通协作（跨部门协作、团队沟通、客户对接）
- 领导力（团队管理、项目管理、决策能力）
- 问题解决（数据驱动、逻辑分析、创新思维）
- 适应力（抗压能力、学习能力、快速适应）

**提取方法：**
识别JD中描述"如何工作"的形容词和动词。

---

### Step 3: 识别岗位核心价值

**核心价值类型：**
- **降本**：降低成本、提高效率、优化流程
- **增长**：用户增长、营收增长、市场拓展
- **合规**：风险控制、合规管理、安全保障
- **创新**：产品创新、技术创新、商业模式创新

**识别方法：**
分析JD中反复强调的业务目标。

---

### Step 4: 对照简历给出调整建议

**输出格式：**

```
📋 JD关键词分析：
硬技能：[Python, SQL, Tableau...]
软技能：[跨部门协作, 数据驱动...]
核心价值：[降本增效, 用户增长...]

📝 简历调整建议：
1. ✅ 已覆盖的关键词（保留/强化）：
   - [关键词] → [强化建议]

2. ❌ 缺失的关键词（补充建议）：
   - [关键词] → [补充方式]

3. 🔄 需要调整顺序的模块：
   - [具体调整建议]
```

## JD匹配实战案例

### 案例：数据分析师岗位

**JD原文（节选）：**
> "负责业务数据分析，使用Python/SQL处理数据，通过Tableau可视化呈现，跨部门协作推动业务增长，具备数据驱动思维，有电商/零售行业经验优先"

**关键词提取：**

```
📋 JD关键词分析：

硬技能：
- Python（编程语言）
- SQL（数据库）
- Tableau（可视化工具）

软技能：
- 跨部门协作
- 数据驱动思维
- 业务分析能力

核心价值：
- 业务增长
- 数据赋能决策

行业经验：
- 电商/零售
```

**简历对照分析：**

```
📝 简历调整建议：

1. ✅ 已覆盖的关键词：
   - Python → 已在技能模块列出，建议在经历中体现具体应用场景
   - SQL → 已覆盖，建议补充"处理XX万条数据"的量化描述

2. ❌ 缺失的关键词：
   - Tableau → 建议在技能模块补充，或在经历中添加可视化项目案例
   - 跨部门协作 → 建议在某段经历中补充协作案例
   - 电商/零售 → 如有相关经验，务必在经历中明确标注

3. 🔄 模块顺序调整：
   - 将"数据分析项目"移至工作经历第一条（最匹配核心职责）
   - 技能模块中Tableau/SQL/Python排序靠前
```

- 产品迭代优化

## 关键词强化策略

### 策略1：显性标注

在技能模块明确列出关键词：
```
技能：
- 数据分析：Python、SQL、Tableau
- 产品管理：用户调研、数据驱动、敏捷开发
```

### 策略2：隐性嵌入

在工作经历中自然嵌入关键词：
```
"通过数据驱动方法论，优化产品迭代策略，用户留存率提升25%"
（嵌入：数据驱动、产品迭代）
```

### 策略3：量化强化

用数字证明关键词能力：
```
"使用Python处理日均50万条数据，通过Tableau可视化呈现，推动运营效率提升30%"
（证明：Python、Tableau、数据分析）
```

## 关键词密度目标

| 关键词类型 | 建议覆盖率 |
|-----------|-----------|
| 硬技能 | 100%（所有硬技能关键词必须出现） |
| 软技能 | 80%以上 |
| 核心价值 | 至少在1段经历中体现 |
| 行业经验 | 如匹配务必标注 |

## 常见JD陷阱识别

### 陷阱1：要求过高（HR复制粘贴）

**识别方法：**
JD包含大量不相关技能要求（如要求产品经理懂C++）

**应对策略：**
重点匹配核心关键词，忽略边缘要求

### 陷阱2：职责模糊

**识别方法：**
JD描述宽泛（如"负责相关工作"）

**应对策略：**
参考同类岗位JD，补充行业标准关键词

### 陷阱3：隐藏要求

**识别方法：**
JD末尾标注"有XX经验优先"

**应对策略：**
如匹配务必突出标注，这是筛选加分项
