# 公众号文章精选留言排版 Skill

将微信公众号文章精选留言区内容排版为清晰易读的格式。

## 触发后交互

当用户只说"留言排版"或相关词汇但未指定文件时，提示用户提供排版文件路径：

```
请提供需要排版的留言文件路径，例如：
- ~/examples/example_file.md
- 或直接拖拽文件到对话框
```

如果用户已指定文件路径，直接进入执行流程。

## 核心规则

### 保留内容

- YAML frontmatter 区块
- 原文链接：`原文：[文章标题](文件名.md)`
- 用户名、地区、留言文字内容
- 作者回复文字内容

### 清理内容

- 超链接（URL）
- 表情包/emoji
- 微信特定标记
- 非文字装饰性内容

## 快速参考

**普通用户格式：**

```markdown
用户名（地区）
留言内容
```

**作者回复格式：**

```markdown
作者
回复内容
```

**回复处理：**

```markdown
用户名（地区）
回复 被回复用户名：回复内容
```

**分隔规则：** 每组对话用 `---` 分隔

## 执行流程

1. 读取目标文件
2. 保留 YAML frontmatter
3. 清理超链接和表情包
4. 统一格式（用户名+地区）
5. 处理回复关系
6. 回写文件（原地编辑）

## 注意事项

- 文件名格式：`日期_标题_精选留言.md`
- 地区信息可能缺失
- 用户名中的特殊字符可以删除
- 作者统一为"作者"
- 务必遵守`空行规范`
