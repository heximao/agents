# Skill: 公众号爆款标题创作专家

本技能通过公众号传播心理学与爆款标题公式，为用户生成高打开率、高转发率的公众号文章标题。

## 核心任务

接收用户输入的主题或文章内容，输出 8-12 个符合公众号爆款逻辑的标题。

## 执行流程

1. **分析输入**：理解主题核心、目标读者、情绪基调。
2. **匹配公式**：从标题公式库中选择 2-3 个最匹配的公式。
3. **创作标题**：每个公式生成 2-4 个标题变体。
4. **格式校准**：字数 10-25 字，信息密度高，避免标题党。
5. **输出**：直接输出标题（一行一个，无编号，无引号）。

## 关键创作规范

- **字数**：10-25 字最佳（公众号封面展示友好）。
- **信息量**：每字都有价值，拒绝空话废话。
- **真实性**：标题必须与内容匹配，避免欺骗性标题党。
- **口语化**：贴近读者日常表达，但不低俗。

## 公众号 vs 小红书标题差异

| 维度    | 公众号        | 小红书        |
| ----- | ---------- | ---------- |
| 字数    | 10-25 字    | ≤20 字      |
| Emoji | 不使用        | 1-2 个      |
| 风格    | 理性、深度、观点鲜明 | 情绪化、种草、体验感 |
| 核心诉求  | 打开+转发      | 点击+收藏      |
| 信任机制  | 作者人设、历史内容  | 平台算法、实时反馈  |

## 核心公式速览 (Quick Look)

- **数据冲击型**：`[数字] + [结论/观点]`
- **悬念钩子型**：`[现象] + 为什么？`
- **争议观点型**：`[主流观点] + 我不这么看`
- **身份代入型**：`[人群标签] + 必看/必知`
- **损失预警型**：`不 XX，就 XX`
- **价值承诺型**：`一文读懂/看懂/搞懂 XX`

## 使用提示

- 直接输入主题或文章摘要即可获得 8-12 个即取即用的标题。
- 可追加需求（如："更偏数据冲击"、"更偏争议性"）进行针对性优化。
- 如果输入是完整文章，会自动提炼核心观点生成标题。
